週報システム プライバシーポリシー

制定日：2026年10月22日

週報システム（以下「本ツール」）は、研究室の中で日報と週報の作成を手伝うツールです。利用者は、管理者と、管理者が直接説明して同意を得た研究室のメンバーに限ります。

1. 集める情報

  • メンバーが Slack のフォームに書いた日報（やったこと、課題、次にやること、進捗の詳細など）
  • Slack のユーザー ID と、所属するグループ
  • 週報を Google ドライブで共有するための、メンバーの Google アカウントのメールアドレス

2. 使う目的

  • 日報をつける習慣を作ること
  • 日報をもとに週報のスライドを作り、報告の品質をそろえること
  • グループの進捗を共有すること

日報の要約は研究室のサーバーの中の AI で行い、外部の AI サービスには送りません。

3. 保存する場所と期間

  • 保存先：研究室のサーバー（暗号化した領域）、Google ドライブ、Slack。Slack と Google は米国の事業者です
  • 保存期間：6か月。暗号化したバックアップは30日で消します
  • Slack と Google の側には、削除のあとも一定期間、写しが残る場合があります

4. Google のユーザーデータの扱い

  • 本ツールは、管理者の Google アカウントで、drive.file の権限（本ツールが作ったファイルだけを読み書きする権限）を使います。週報とバックアップのファイルを作り、保存し、メンバーに共有し、保存期間を過ぎたら削除するためだけに使います
  • 本ツールが作ったファイル以外の Google ドライブのファイルには、アクセスしません
  • Google のユーザーデータを、第三者に販売・提供したり、広告に使ったり、AI のモデルの学習に使ったりしません
  • 本ツールによる Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います

5. 見られる人

本人、同じグループのメンバー、そのグループの閲覧を認められた人、管理者です。管理者が日報を読むのは、障害の対応、本人からの請求、不正の調査のときに限ります。

6. 開示と削除の請求

自分のデータの開示や削除は、管理者に求めることができます。脱退するときは、その人の日報と週報を削除します。
